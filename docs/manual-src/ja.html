01インストールと初回起動
01

インストールと初回起動

管理者権限なしで、自分のアカウントにだけインストールします。動画と音に使う ffmpeg は、セットアップ中に GitHub から取得します。

セットアップ

  1. 受け取った zip をすべて展開します。zip の中から直接実行すると、セットアップがファイルを見つけられません。
  2. Setup.cmd をダブルクリックします。「Windows によって PC が保護されました」が出たら 詳細情報 → 実行 を押します。まだコード署名がないために出る画面です。
  3. セットアップは 3 段階で進みます: プログラムのコピー、ffmpeg、ショートカットと .void ファイルの関連付け。デスクトップのショートカットを作るか、すぐ起動するかを聞かれたら、Enter で既定(はい)を選べます。

初回起動では Windows の表示言語に合わせて、韓国語、英語、日本語のいずれかで開きます。あとから 設定 › 言語 で変えられます。

ffmpeg

動画の読み込みと再生、音、動画の書き出しは、FFmpeg プロジェクトの ffmpeg を一緒に動かして処理します。写真、絵、文字、3D 空間、画像の書き出しは ffmpeg なしで使えます。

  • すでに ffmpeg が入っていれば、それを使います (PATH、または winget install Gyan.FFmpeg で入れたもの)。
  • なければダウンロードするか聞きます。GitHub の BtbN/FFmpeg-Builds の最新リリースビルド(約 80 MB)を取得し、SHA-256 チェックサムを確かめてから、インストール先の ffmpeg フォルダーにだけ置きます。
  • 取得に失敗してもセットアップは最後まで進みます。あとで Setup.cmd をもう一度実行すれば、その段階だけやり直せます。ffmpeg がないまま動画を入れると、下のステータスバーに ffmpeg が見つかりません と出ます。

更新と削除

  • 新しいバージョンへの更新: 新しい zip の Setup.cmd を実行すると、同じ場所に上書きします。設定とプロジェクトはそのまま残ります。
  • 削除: Windows の設定 › アプリ › インストールされているアプリ › Drifting VOID › アンインストール。設定ファイルも消すかは別に聞き、.void プロジェクトには触れません。

画面の見かた

中央の暗い地が果てのないキャンバスで、ツールとプロパティはその上に浮かぶガラスのカードにあります。アクセント色(琥珀色)は、いまオンのものにだけ使います。

  • 1メニュー ファイル、編集、設定
  • 2ツールバー ツールごとにショートカット 1 文字 (4 章の表)。マウスを乗せると使い方が出ます
  • 3現在の色 押すとパレット
  • 4キャンバス 果てがなく、写真は元の解像度で置かれます
  • 5ツール · 選択中の項目 いまのツールの設定と、選んだレイヤーのプロパティ
  • 6レイヤー 上へ、下へ、複製、削除、FX レイヤーを追加のボタン。ドラッグで並べ替え、ダブルクリックで名前の変更
  • 7ステータスバー 倍率、座標、直前の操作

カードとパネル

カードの見出し(▾ ツール、▾ 選択中の項目)を押すと折りたためます。オン/オフの値はスイッチ、1 つを選ぶ値は並んだボタンです。マウスを乗せると短い説明が出る欄が多いので、はじめはゆっくり見て回ってください。

設定メニュー

  • ライト · ダーク · システム: 画面のテーマ。
  • 言語: 한국어、English、日本語。
  • UI 倍率: 90–150 %。Ctrl+Alt++/−/0。
  • ガラス効果(オフで不透明なカード)、パネルの影、ガラスの縁の屈折の強さとリムの幅、カードの角と滑らかさ。
  • 指で描く、Tab の待ち時間 (10 章)。

Ctrl+H で UI をすべて隠し、もう一度押すと戻ります。

キャンバスの操作

マウス、ペンタブレット、タッチのどれでも使えます。ペンの筆圧は Windows Ink で読み取ります。

タッチ
指 1 本で表示の移動、2 本でズームです。指でも描くには 設定 › 指で描く をオンにします。ペンはいつでも描けます。

ダイヤル

ほとんどの値は目盛りのリング(ダイヤル)で変えます。左右にドラッグすると値が変わり、Shift で微調整、ホイールは 1 目盛りずつです。既定値のある値は、変えると ↺ が出て、押すと戻ります。1 回のドラッグや続けて回したホイールは、元に戻す 1 回で戻ります。

ドロップダウン

クリックで一覧が開きます。閉じたドロップダウンの上でホイールを回すと、前後の項目にすぐ切り替わります。押したまま下へドラッグすると一覧が開き、選びたい項目で離すとそれが選ばれます。

数値欄

数値欄には計算式をそのまま書けます: 40*1.5、2^3+1、かっこも使えます。空のまま Enter を押すと 0 です。

元に戻す

Ctrl+Z で元に戻す、Ctrl+Y でやり直し。保存せずに閉じようとすると、先に確認します。

描画と色

ブラシはピクセル(ラスター)で、ペンはベクターのストロークで描きます。描き始めると描画レイヤーができ、空になると自動で消えます。

ブラシの設定

  • プリセットごとに既定の硬さと不透明度があります。
  • 筆圧 → サイズ、筆圧 → 濃度: ペンを押す強さで太さや濃さが変わります。
  • 手ぶれ補正: 筆がペンをどれだけ遅れて追うか。大きいほど線がなめらかで、遅れて追います。ペンを止めると、筆がペンの下まで追いつきます。
  • サイズ: Ctrl+ドラッグ、または [ ]。ペン、消しゴム、図形の線の太さも Ctrl+ドラッグで変えます。

色

キャンバスのどこでも Alt+クリックで OKHSV パレットが開きます。人の目に均等に見えるよう整えた色空間なので、明るさを変えても色味がずれにくくなっています。

類似色マップをオンにすると、いまの色と明るさが同じ色、彩度が同じ色を 2 枚のマップで見せます。下の列はよく使う色です。色の欄にはどれも 16 進コードを書けて、コピー、貼り付けもできます。複数のレイヤーを選んだまま色を選ぶと、すべてに適用されます。

写真、文字、図形

写真は元の解像度のまま入り、縮小しても元のピクセルは残っています。

読み込み

  • ファイルをウィンドウにドロップ、Ctrl+I、または Ctrl+V で貼り付け。文字を貼り付けるとテキストレイヤーになります。
  • ブラウザーから直接: Chrome や Edge の画像をウィンドウにドラッグすると写真として入ります。画像のアドレスをコピーして貼り付けても写真になります。画像でないリンクは文字として入ります。
  • PNG、JPEG、WebP、BMP、TIFF、GIF、スマートフォンの HEIC/HEIF。動く GIF は、くり返し再生される透明な動画レイヤーになります (ffmpeg が必要)。
  • 動画(mp4、mov、mkv、webm など)と音(mp3、wav など)は 11 章を見てください。

写真のプロパティ

サイズ % · 回転 °元のサイズ、回転 0° で一度に戻す
切り抜き… (C)切り抜いても元は残り、切り抜き解除で戻ります
補正明るさ、コントラスト、彩度
クロマキー選んだ色を透明に (グリーンバックの除去)
合成描画モード

文字

  • T でキャンバスを押して入力します。ボックスは入力に合わせて広がり、折り返し幅をオンにするとその幅で改行します。
  • フォントは、この PC に入っているすべてのフォントから選べます。
  • 背景ボックスをオンにすると、左右余白、上下余白、角、ボックスの枠線とその太さを決められます。
  • 文字の縁取りはボックスとは別にオンにでき、色と太さを決めます。
  • 余白と太さは文字サイズに対する % なので、文字を大きくしても見た目が保たれます。変えても文字はその場から動かず、ボックスだけがまわりに広がります。
  • 新しい文字は、最後に使った設定で始まります。
フォント
選んだフォントにない文字(Arial の日本語など)は、別のフォントで代わりに描かず、空の四角(□)で表示します。そのフォントが文章に合っていないという印なので、その文字を含むフォントを選んでください。

選択と変形

レイヤーを丸ごと選ぶことも、ペンのストローク 1 本やブラシのピクセルの一部だけを選んで動かすこともできます。

まとめて扱う

  • 複数を選ぶとハンドルが 1 つにまとまり、共通の中心を基準にサイズを変えたり回したりします。
  • 回転中に Shift か Ctrl: 始めの角度から 15° ずつ。Alt: 0° から 15° ずつ。
  • プロパティカードで値がそろわない欄は — と表示されます。そこに値を入れると、すべてがその値になります。ほかの欄を変えると、変えた値だけがすべてに入ります。

選択ツールで G 移動、R 回転、S サイズ。マウスを動かして決め、クリックか Enter で確定、Esc か右クリックで取り消します。3D 空間の中のレイヤーは 3D の方式で動きます (10 章)。

07マスク

マスク

レイヤーの一部を、消さずに隠します。高解像度の写真から物をきれいに切り抜くことに合わせて作りました。

作成と塗り

レイヤーの行やプロパティカードのマスクを押すと、そのレイヤーの下にマスクレイヤーができます。マスクを選んだまま:

  • ブラシ、ペン、四角形で塗ったところが隠れます。隠れた部分はキャンバスで赤く見えます。
  • 消しゴムで元に戻ります。Alt を押して四角形を描いても戻ります。
  • 強さ、反転で隠し方を変えます。
  • 追従: マスクがどのレイヤーに付いて動くか (ふつうはその写真)。
  • 空にするまたは Delete: マスクを空にします。

自動で切り抜く

3 つのモードは選択ツール(V、Q)でだけ動きます。モードをオンにすると選択ツールに切り替わり、ほかのツールを選ぶとそのツール本来の動作をします。どれも Alt を押すと、逆に元に戻します。

自動選択クリックした所と似た面を隠します。許容誤差で範囲を調整
GrabCut四角くドラッグすると、その中で浮いて見える物を隠します
ハサミ境界に沿って輪郭を描き、閉じます (下記)
整える · 境界の移動境界を絵に合わせてなめらかに (0: くっきり) · + は隠す範囲を広げてすき間を埋め、− は狭めます

ハサミ

  • ドラッグ: カーソルを境界の近くで動かすと、線が境界に吸い付いて追い、アンカーが自動で置かれます。
  • クリック · 右クリック: その場所にアンカーを置きます。近くのいちばんはっきりした境界に吸着します。
  • 閉じる: 最初の点を押すか Enter。Shift を押して閉じると、GrabCut でもう一度整えます。
  • Esc 1 回で描きかけの輪郭を取り消し、もう 1 回でハサミのモードを終えます。
  • 境界: シャープは境界線できれいに切り、写真のぼけは写真の中の境界がぼけている分だけやわらかく切ります。
写真のマスク
空のマスクで写真の上をはじめて切り抜くと、その写真の元のピクセル解像度で作られます。そのあと写真を動かしたり回したり縮めたりしても、マスクはそのまま付いていきます。

FX レイヤー

ピクセルの代わりにフィルターを 1 つ持つレイヤーです。一覧で自分より下にあるレイヤーすべてにフィルターをかけ、いちばん上に置けばすべてにかかります。元のレイヤーは変わりません。

使い方

  1. レイヤーカードのきらめきボタン、または編集 › FX レイヤーを追加。選んだレイヤーの上にできます。
  2. カードのフィルターで効果を選び、値をダイヤルで決めます。値ごとにタイムラインのキーを打てます。
  3. 合成は最初コピー(下の絵をフィルターの結果に置き換え)です。ほかのモードで混ぜることもできます。
  4. FX レイヤーにもマスクを付けて、一部にだけかけられます。レイヤーの順番を変えると、かかる範囲が変わります。

フィルター

種類フィルター
ぼかしとシャープガウスぼかし、モーションぼかし、アンシャープマスク
色明るさ・コントラスト、色相・彩度・明度、レベル補正、トーンカーブ、白黒、反転、ポスタリゼーション、しきい値、グラデーションマップ、チャネルをアルファに
質感と画面ノイズ、ビネット、色収差、モザイク、ハーフトーン、グロー

ノイズ、モザイク、ハーフトーンはキャンバスに固定した格子を使うので、表示を動かしても模様がすべりません。フレームごとに変化をオンにすると、ノイズがフレームごとに変わります。ビネットと色収差は撮影中のカメラ(なければ書き出し範囲、それもなければ内容全体)を基準にし、カメラが回ると一緒に回ります。

トーンカーブはグラフで直接編集します。空いた所をクリックすると点が増え、点をドラッグして動かし、グラフの外へドラッグするかダブルクリックすると消えます。チャネルで RGB と R・G・B を個別に選べ、量はキーフレームで動かせます。点を右クリックすると接線の種類を選べ、フリーはハンドルで傾きを決めます。チャネルをアルファには R・G・B・L(輝度)をカーブに通してアルファにします。

3D 空間

写真の中で平行な辺に沿って線を何本か引くと、その写真を撮ったカメラを割り出します。その空間に文字や絵を立てたり寝かせたりして、写真の遠近に合わせて置けます。

空間を作る K

  1. 写真の上をドラッグして空間の範囲を決めるか、写真を押してその写真に合わせます。
  2. 現実で互いに平行な辺に沿って線を引きます。軸は 1 2 3 または X Y Z で切り替えます: X Y は床の方向、Z は上。2 つの軸に 2 本ずつ、少なくとも 4 本必要です。
  3. 線の端をドラッグして整えます。ドラッグ中はルーペが出て、Shift で境界を強調して見せます。Delete か右クリックで線を消します。
  4. カメラは線を引くたびにすぐ計算し直します。レイヤーをレイヤーカードの空間フォルダーにドラッグすると、見えているとおりの姿で空間に入ります。

線を検出と自動選択

線を検出は写真の中のまっすぐな辺を探し、薄い色の候補として見せます。候補を押すといまの軸の線になり、そのままドラッグして端を整えられます。候補が勝手に軸を決めることはありません。

自動選択を押すと、候補の中から互いに直角に合う 3 方向を選び、軸ごとに何本かずつ入れます。結果がおかしければ元に戻して、手で選んでください。

空間のカード

基準の長さ · メジャー写真の中の 1 つの長さを実際のメートルで教えると、ほかの長さを測れます

タイムライン、動画、音

キャンバスをそのまま動く絵にします。動画と音の機能には ffmpeg が必要です。

キーアニメーション

  • Alt+A で再生・停止、, . で 1 フレームずつ。
  • I は選んだものの今の値をキーにし、Alt+I は再生ヘッド位置のキーをすべて消します。プロパティの行ごとにキーボタンがあり、値を 1 つずつキーにでき、< > で前後のキーへ飛びます。
  • 各レイヤーの名前の行の下に、キーのある値(位置、サイズ、回転、不透明度、3D の位置、厚み、音量、FX の値など)が 1 行ずつ出ます。キーは自分の行でだけ選び、動かし、消します。
  • 自動キーをオンにすると、変えた値にだけキーが入ります。
  • キーはドラッグで動かし、Shift+ドラッグで複数選びます。再生ヘッドを Shift を押したままドラッグすると、近くのキーに吸着します。キーの形は補間(スムーズ、リニア、ホールド)を表します。
  • 名前の行を右クリックすると、レイヤーが現れる時と消える時を決められます。

カメラと録画

  • F ツールでキャンバスのカメラを作り、位置とサイズにキーを打って画面を動かします。
  • ● 録画をオンにして描くと、ペンとブラシのストロークが描いた順番と速さのまま再生されます。
  • 再生時は描き終えたフレームをメモリーにためておく(再生キャッシュ)ので、重い場面もなめらかに再生できます。

動画と音のレイヤー

  • 動画をドロップすると、タイムラインではクリップになります。動かしたり前後を切ったりでき、クリップの外では最初か最後のフレームで止まっています。
  • プロパティカードで、いまのフレームを写真レイヤーにできます。
  • 音のファイルはキャンバスにスピーカーの印で置かれ、タイムラインで動かしたり切ったりできます。音量にもキーを打てます。

書き出しと保存

キャンバス全体ではなく、欲しい部分だけを欲しいサイズで書き出します。書き出しは画面と同じ GPU レンダラーで描きます。

範囲を決める F

書き出し範囲ツールで四角を描きます。何かを選んだまま使うと、それにぴったり合わせます。

画像 Ctrl+E

PNG か JPEG で書き出します。余白は範囲の外に取る距離で、サンプル数を上げると大きく描いてから縮め、ふちがよりなめらかになります。背景は透明、白、選んだ色から決めます。Ctrl+Shift+C は範囲をそのままクリップボードへコピーします。

動画 Ctrl+Shift+E

範囲書き出し範囲かカメラ、内容全体、いまの画面
サイズ幅か高さを基準に。はじめは範囲の実際のピクセル数
形式H.264、H.265、AV1、ProRes 4444(透明)、VP9(透明)、GIF、PNG 連番
画質の基準品質の値(低いほど高画質)、またはビットレート
GPU エンコードNVIDIA のグラフィックカードなら既定でオン (NVENC)
サンプル数 · 背景1–4 倍 · 透明、白、色
音声を含むタイムラインの音と動画の音を混ぜて入れます

進み具合はウィンドウに出て、いつでも取り消せます。

保存

Ctrl+S 保存、Ctrl+Shift+S 名前を付けて保存、Ctrl+O 開く、Ctrl+N 新規。.void ファイルをダブルクリックしても開けます。

動画と音のファイル
写真は .void の中に一緒に保存されますが、動画と音は元のファイルを参照します。プロジェクトを別の PC へ移すときは、動画と音のファイルも一緒に移してください。

ヘルプとライセンス

おかしな点があれば、小さなことでも知らせてください。次のものを一緒に送っていただくと、早く直せます。

問題を知らせるとき

  • 何をしていてどうなったか、もう一度やっても同じか。
  • アプリが突然終了したときは %APPDATA%\DriftingVOID\crash.log。
  • できれば画面のキャプチャーと、問題が起きた .void ファイル。
  • グラフィックカードとペンタブレットの種類。

既知の制限

  • Windows 10/11 専用です。DirectX 12 か Vulkan に対応したグラフィックカードが必要です。
  • コード署名がないため、初回起動時に Windows の保護画面が出ます。
  • フォントにない文字は別のフォントで代わりに描かず、空の四角で表示します (意図した動作)。
  • とても大きな録画ペンレイヤーは、読み込みに少し時間がかかることがあります。
  • 再生キャッシュはメモリーを多く使うことがあります (最大で物理メモリーの 75 %)。

ffmpeg とライセンス

Drifting VOID は動画の処理に FFmpeg を別のプログラムとして実行します。ffmpeg はこの配布ファイルに含まれていません。セットアップ中に BtbN/FFmpeg-Builds の公開ビルド(GPL)を取得してインストール先の ffmpeg フォルダーに置き、そのフォルダーの LICENSE.txt にライセンス全文が、SOURCE.txt に取得したファイル名、チェックサム、入手元があります。

日本語の画面フォント Pretendard JP は SIL Open Font License 1.1 で同梱しており、インストール先の fonts にライセンスがあります。韓国語と英語の画面は Pretendard などインストール済みのフォントを先に探し、なければ Malgun Gothic を使います。
